# Bundled fonts

All three are licensed under the SIL Open Font License 1.1, which permits
bundling in a commercial game including a Steam release. Full text in OFL.txt.

| File        | Family         | Designer                        |
|-------------|----------------|---------------------------------|
| display.ttf | Oswald         | Vernon Adams, Kalapi Gajjar     |
| body.ttf    | Barlow         | Jeremy Tribby                   |
| mono.ttf    | JetBrains Mono | JetBrains                       |

`mono.ttf` is used for every timed or compared number — ET, RT, trap speed,
RPM. It has tabular figures, so a 1 occupies the same width as an 8 and the
readouts do not jitter as they count.
